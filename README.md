# OdontoPrep UJAT

Aplicación educativa Flutter para estudiar un temario personal y propuesta de preparación en Odontología. El contenido no constituye una guía oficial de la UJAT.

## Abrir el proyecto

```powershell
cd c:\Users\diegu\OneDrive\Desktop\admisionujt\admujt
code .
```

## Ejecutar

```powershell
flutter pub get
flutter run -d windows
flutter run
```

Para Android, inicia un emulador o conecta un dispositivo Android y ejecuta `flutter run` seleccionando el dispositivo disponible.

Consulta `docs/architecture.md` para conocer la arquitectura y los siguientes pasos.
